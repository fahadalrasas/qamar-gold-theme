# Qamar Gold Theme

هذا مستو��ع يحتوي على نسخة جاهزة من ثيم متجر الذهب بأسلوب فاخر باستخدام الألوان البيج، أوف وايت، والذهبي الناعم، مستوحى من فكرة "قمة زاوية الشفاء".

## ما داخل المشروع
- `index.html` — الصفحة الرئيسية للمتجر
- `styles.css` — جميع تنسيقات الثيم
- `script.js` — تأثيرات بسيطة على الأزرار

## التشغيل محليًا
1. افتح المجلد في جهازك.
2. شغّل الملف `index.html` في المتصفح.
3. إذا رغبت، استخدم Live Server من VS Code لتجربة الصفحة بشكل أفضل.

## استخدامه كـ Front-End جاهز
يمكنك استخدام هذا المشروع كـ:
- نموذج للمتجر قبل التفعيل
- تصميم UI جاهز للـ Shopify / Salla / WooCommerce
- قالب لتخصيص الصفحة الرئيسية

## رفعه على منصة سلة (Salla)
لرفع هذا التصميم على منصة سلة، اتبع الخطوات التالية:
1. قم بضغط المجلد إلى ملف ZIP.
2. ادخل إلى لوحة تحكم متجر سلة.
3. انتقل إلى قسم "المظهر/الثيمات" أو "القوالب المخصصة" حسب واجهة الحساب.
4. اختر خيار "رفع قالب/مظهر" أو "Upload Theme".
5. قم بتحميل ملف ZIP.
6. بعد التحميل، اضبط الاسم، الألوان، الصور، وأيقونات المنتجات داخل إعدادات المتجر.

## ملاحظات مهمة
- هذا المشروع هو نسخة UI/Front-End جاهزة، وليست نسخة رسمية سداسية تتوافق مع بنية سلة بشكل كامل، لذلك قد تحتاج إلى تعديل بعض العناصر ليناسب متجر سلة بشكل دقيق.
- إذا رغبت، أستطيع في الخطوة التالية تحويل هذا التصميم إلى نسخة متوافقة مع سلة أو Shopify بشكل كامل، مع ملفات قالب قابلة للرفع من داخل النظام.
